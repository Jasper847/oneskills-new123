### 1. Structural Layer (Semantic HTML5 & Accessibility)
- **Semantic Landmarks:** Full utilization of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<figure>`, `<figcaption>`, `<dl>`, `<dt>`, `<dd>`, and `<ol>`.
- **Keyboard Navigation:** High-contrast skip-to-content bypass link (`.skip-link`) for instantaneous focus management.
- **W3C WAI-ARIA Conformance:** 
  - Radio button groups use `role="radio"` with `aria-checked="true|false"` (never `aria-selected`).
  - Tab button interfaces use `role="tab"` with `aria-selected="true|false"` (never `aria-pressed`).
  - Dynamic status areas use polite live announcements (`aria-live="polite"`).
- **Accessible Motion:** Universal `@media (prefers-reduced-motion: reduce)` rules that automatically halt continuous floating loops, translations, and transitions for sensitive users.

### 2. Presentation Layer (8px Grid & Design Tokens)
- **Spatial Rhythm:** Strict 8-pixel spacing system (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `80px`) across all padding, margins, and layout gaps.
- **CSS Custom Properties:** Semantic design tokens (`--bg`, `--surface-card`, `--brand-purple`, `--text-primary`, `--border-default`) enabling seamless Light and Dark mode rendering without layout recalculations.
- **Responsive Layout Engine:** Fluid CSS Grid and Flexbox systems supporting viewports from 320px mobile screens up to 4K ultra-wide monitors.

### 3. Behavioral Layer (Pure Vanilla ES6+)
- **Zero Third-Party JS Frameworks:** Zero React, Vue, or jQuery overhead for ultra-low latency, 0ms hydration delay, and immediate Time to Interactive (TTI).
- **Interactive Fee Switcher:** Instant toggle between Full Track and Installments updating both desktop tuition cards and mobile sticky docks.
- **Batch Slot Selector:** Live selection of Morning, Afternoon, Evening, or Weekend cohorts without artificial scarcity timers.
- **Commuter Town Matrix:** Interactive route guide for students traveling from Sheikhupura, Farooqabad, Safdarabad, Muridke, and Nankana Sahib.

## 💻 Local Development & Setup

This project requires **zero build tools, zero bundlers, and zero `npm install`**. It runs natively in any standard modern web browser.

### Starting the Local Development Server

A dedicated, lightweight PowerShell HTTP server script is included in the project root:

```powershell
# Open terminal in the project directory
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Once running, the local environment is accessible at:
- **Local URL:** `http://localhost:8080/`
- **Course Hub:** `http://localhost:8080/courses/`
- **Flagship Course:** `http://localhost:8080/courses/freelancing-mastery.html`

Alternatively, use any standard static HTTP server:

```bash
# Python 3
python -m http.server 8080

# Node.js (npx)
npx serve -l 8080
```

## 🔍 SEO & Structured Data Architecture

Every course page incorporates a strictly validated [Schema.org](https://schema.org) JSON-LD structured data graph:

1. **`@type: Course`**: Detailed curriculum breakdown, duration (`P12W`, `P10W`, or `P8W`), official tuition (`offers.price`), onsite instructional mode, and designated faculty mentors.
2. **`@type: AggregateRating`**: Verified 5.0/5.0 rating with 15 verified local reviews (`ratingCount: 15`).
3. **`@type: PostalAddress`**: Sheikhupura campus address with verified postal code (`39350`).
4. **`@type: BreadcrumbList`**: Full hierarchical navigation trail (`Home > Courses > [Course Title]`).
5. **`@type: FAQPage`**: Direct synchronization with visible on-page FAQs (laptop requirements, 1-month internship opportunity, 14-day refund guarantee from fee payment date).
