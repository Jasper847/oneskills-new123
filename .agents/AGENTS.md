# Agent Instructions & Guidelines

## Core Principles

- Cut taglines, helper text and secondary labels. If a screen needs them to make sense, fix the layout.
- Make the best decision that will elevate all three: the user experience (UX), developer experience (DX), and agent experience (AX) always, without breaking anything.

## Design & Engineering Standards

- Always use semantic HTML5 elements for better accessibility and SEO.
- Maintain consistent spacing using an 8 pixel grid system throughout the design.
- All animations should respect preferred reduce motion for accessibility.
- Use CSS variables for all colors to enable easy theme switching.
