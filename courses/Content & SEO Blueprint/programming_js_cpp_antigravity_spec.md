## 6. Section 04: Complete 8-Module, 10-Week (60-Hour) Curriculum Accordion
*(Engineered to rank #1 for C++, JavaScript, OOP, Data Structures, and ICS/BSCS Programming in Sheikhupura while matching the exact tags on your homepage `index.html`: `Algorithms`, `OOP Logic`, and `ES6+`.)*

* **Subtitle**: Every week combines whiteboard logic dry-runs with live hands-on coding in our Sheikhupura computer lab.

### Phase 1 — Weeks 1 to 5: C++ Programming Fundamentals, Pointers, OOP & Data Structures

#### Module 01 (Weeks 1–2): Algorithmic Thinking & C++ Programming Fundamentals (PF)
* **Badge**: `50+ Logic Drills`
* **Topics Covered**:
  * How computers execute code: Machine code, compilers (`GCC/MinGW`), interpreters, and setting up **VS Code**
  * **Problem-Solving Before Coding**: Designing Flowcharts, Pseudocode, and paper Dry-Runs
  * **C/C++ Core Syntax**: Variables, Data Types (`int`, `float`, `double`, `char`, `bool`), Constants, and Input/Output streams (`cin`, `cout`)
  * Operators & Expressions: Arithmetic, Relational, Logical, and Bitwise operators
  * **Control Flow Mastery**: Conditional logic (`if-else`, nested `if`, `switch-case`, ternary operators)
  * **Looping & Pattern Logic**: `for`, `while`, and `do-while` loops, nested loops, star/number pyramid patterns, and mathematical series
  * **Lab Project 01 (C++)**: Build a **Scientific CLI Calculator, Grading System & Number-Guessing Logic Game**.

#### Module 02 (Week 3): Functions, Arrays, Strings, Pointers & Memory Management in C++
* **Badge**: `Memory & Pointers Lab`
* **Topics Covered**:
  * **Modular Programming with Functions**: Function declarations, parameters, return types, **Pass-by-Value vs. Pass-by-Reference**, and function overloading
  * **Recursion**: Understanding base cases, call stacks, factorials, and Fibonacci recursion
  * **1D & 2D Arrays**: Array traversal, matrix operations, searching, and frequency counting
  * **C-Strings vs. C++ `std::string`**: Text manipulation, palindromes, and character parsing
  * **Pointers & Memory Architecture (Made Simple)**: How RAM addresses work (`&` and `*`), pointer arithmetic, dynamic memory allocation (`new` and `delete`), and avoiding memory leaks
  * File Handling in C++ (`ifstream`, `ofstream`): Saving and reading permanent records from disk

#### Module 03 (Week 4): Object-Oriented Programming (OOP) Mastery in C++
* **Badge**: `Project 02 Included`
* **Topics Covered**:
  * Why procedural code breaks in large software—and how **Object-Oriented Programming (OOP)** solves it
  * **Classes & Objects**: Attributes (data members), Methods (member functions), Constructors, and Destructors
  * **The 4 Pillars of OOP**:
    1. **Encapsulation & Data Hiding**: `private`, `protected`, and `public` access specifiers, Getters & Setters
    2. **Abstraction**: Designing clean interfaces and header files
    3. **Inheritance**: Single, Multilevel, and Multiple inheritance for reusable code
    4. **Polymorphism**: Compile-time (operator/function overloading) and Run-time (`virtual` functions)
  * **Lab Project 02 (C++ OOP)**: Build a **Complete Bank Account / Library / Student Management System with File Storage**.

#### Module 04 (Week 5): Data Structures, Algorithms (DSA) & C++ STL
* **Badge**: `Interview & University Prep`
* **Topics Covered**:
  * Introduction to **Time & Space Complexity (Big-O Notation: `O(1)`, `O(log n)`, `O(n)`, `O(n²)`)**
  * **Searching & Sorting Algorithms**: Linear Search, Binary Search, Bubble Sort, Selection Sort, and Insertion Sort
  * **Core Data Structures**: How Arrays, Structs, Linked Lists, Stacks (`LIFO`), and Queues (`FIFO`) work
  * **C++ Standard Template Library (STL)**: Using `std::vector`, `std::map`, `std::set`, and `std::sort` to solve competitive programming problems rapidly

#### Module 05 (Week 6): Transitioning from C++ to Modern JavaScript (`ES6+`)
