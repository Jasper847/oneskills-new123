Computational Philosophy

The Dual-Engine Programming Strategy

Learning syntax alone makes you fragile. Learning how computers allocate memory in C++ makes you an unstoppable software engineer in JavaScript and beyond.

Track 01

Engine 1: C++ Low-Level Logic & Memory

C++ exposes the underlying truth of computing. You will master variables, memory addresses, pointer dereferencing, dynamic memory (`new`/`delete`), class structures, and big-O algorithmic complexity. This directly prepares you for university exams and technical software interviews.

Topics: Pointers, Heap vs Stack, OOP & DSA
Track 02

Engine 2: JavaScript Modern Web Applications

JavaScript brings your logic to life in the browser. You will bridge your C++ understanding of objects and functions into modern ES6+ syntax, asynchronous event loops, API fetching, and interactive DOM manipulation—ready to step into full-stack web and app engineering.

Topics: ES6+, Event Loop, DOM, REST APIs & GitHub
Structured Syllabus

10 Weeks · 30 On-Campus Sessions · 60 Code Exercises

Divided into 2 distinct phases: C++ Computational Foundations followed by Modern JavaScript Application Development.

Weeks 1–2

C++ Algorithmic Foundations: Variables, Control Structures & Functions

6 Sessions · 12 Exercises
  • Setting up MinGW, GCC compiler, and VS Code C++ environment.
  • Data types, memory sizes, arithmetic operators, conditional branching (if-else, switch-case), and nested iteration loops (for, while, do-while).
  • Modular programming: function declarations, pass-by-value vs pass-by-reference, function overloading, and recursion.
Tools: VS Code, MinGW, GDB Debugger Practical Exercise: Algorithmic prime number & Fibonacci generator
Weeks 3–4

Arrays, C-Strings, Memory Addresses & Pointer Dereferencing

6 Sessions · 12 Exercises
  • One-dimensional and multi-dimensional arrays: matrix operations, traversal, and linear searching.
  • Understanding RAM: stack memory vs heap memory, memory leaks, and pointer arithmetic (`*` and `&` operators).
  • Dynamic memory allocation using `new` and `delete`, dangling pointer prevention, and dynamic array resizing.
Core Concept: Direct RAM Address Manipulation Practical Exercise: Dynamic matrix multiplication with pointers
Week 5

Object-Oriented Programming (OOP): Classes, Encapsulation & Inheritance

3 Sessions · 6 Exercises
  • Constructors (default, parameterized, copy) and destructors for resource management.
  • Access specifiers (private, protected, public), getters/setters, and data encapsulation.
  • Inheritance hierarchies: single, multiple, multilevel, and hierarchical inheritance with `super`/base class calls.
Core Concept: Real-World Modeling with C++ Classes Project: University student & faculty record management system
Week 6

Polymorphism, Virtual Functions & File Stream Persistence

3 Sessions · 6 Exercises
  • Compile-time polymorphism (function & operator overloading) vs runtime polymorphism (virtual functions & vtables).
  • Abstract classes, pure virtual functions, and building software interfaces.
  • File I/O with `fstream`: reading, writing, updating, and serializing binary data to disk files.
Persistence: Disk File Reading & Writing in C++ Project: Console Banking Management System with file storage
Week 7

Data Structures: Linked Lists, Stacks, Queues & Big-O Notation

3 Sessions · 6 Exercises
  • Time & space complexity: calculating O(1), O(log n), O(n), and O(n²) operations.
  • Singly linked lists: node creation, head insertion, tail insertion, and deletion algorithms.
  • Stack and Queue implementations using dynamic arrays and linked lists (LIFO vs FIFO principles).
Algorithmic Theory: University DSA Exam Alignment Practical Exercise: Undo/Redo stack engine in C++
Week 8

Modern JavaScript ES6+ Foundations: Bridging C++ Logic to the Web

3 Sessions · 6 Exercises
  • How JavaScript executes: V8 engine, Call Stack, Event Loop, and single-threaded asynchronous nature.
  • Comparing C++ objects with JavaScript Object Literals, Maps, and dynamic prototypes.
  • ES6+ array utilities: `.map()`, `.filter()`, `.reduce()`, `.find()`, and arrow functions.
Environment: Node.js & Modern Browser DevTools Practical Exercise: Algorithmic data transformations in JavaScript
Week 9

DOM Manipulation, Event Handling & Asynchronous Fetch API

3 Sessions · 6 Exercises
  • Document Object Model (DOM) queries, dynamic element creation, and event delegation.
  • Promises, async/await syntax, and error handling with try/catch blocks.
  • Consuming external REST APIs: fetching JSON datasets and rendering dynamic data cards.
Web Interactivity: Live API Data Binding Project: Dynamic Crypto & Stock Price Tracker web app
Week 10

Capstone Project Defense, Git Version Control & Graduation

3 Sessions · 6 Exercises
  • Git fundamentals: initializing repositories, commit discipline, branch management, and pushing to GitHub.
  • Building an algorithmic sorting visualizer that renders Bubble Sort, Insertion Sort, and Quick Sort in real time.
  • Final project code review, interview preparation questions, and certificate issuance.
Milestone: GitHub Portfolio & Capstone Project Defense Outcome: Dual-Engine Mastery in C++ & Modern JavaScript

Frequently Answered Questions

Common Questions About Programming at OneSkills

Why teach both C++ and JavaScript together in one course?

C++ teaches you how computers work at the hardware level: memory management, pointer manipulation, CPU cycles, and strict Object-Oriented principles. JavaScript translates that algorithmic strength into the modern web, allowing you to build real interactive software and APIs.

Will this course help college and university students with their exams?

Yes. Our syllabus directly maps to the core programming, OOP, and Data Structures (DSA) curricula of University of the Punjab, Virtual University, GCUF, and UET. We provide 1-on-1 bug troubleshooting for semester projects and exam preparation.

Do I need to bring my own laptop to class?

Yes. Students must bring their own laptops. OneSkills Academy does not provide dedicated individual computers. Having your personal compiler, IDE (VS Code, Code::Blocks), and Git environment on your own machine ensures uninterrupted study at home.

Can an absolute beginner learn programming in this course?

Yes. We begin with core computational thinking, flowcharts, conditional logic, and simple loops before advancing into pointers, dynamic memory allocation, and object-oriented architectures.

What practical projects will I build?

You will build: 1) A full Console Banking & Record Management System in C++ with file stream persistence; 2) An interactive Sorting & Searching Algorithm Visualizer; and 3) An asynchronous JavaScript web application interacting with external REST APIs.

What is the tuition fee and refund guarantee policy?

Tuition is PKR 25,000 for the full 10-week program with flexible payment options (2 installments of PKR 12,500). Students may request a full refund within 14 calendar days of their fee payment date.
